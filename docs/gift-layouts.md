# Спільні шаблони подарунків

Дні 1–8 використовують спільну шапку: назва, номер та кнопка закриття. Ширина картки, шрифти, відступи, кнопки й оформлення нагород узгоджені. Високі картки прокручуються всередині, кнопка закриття залишається доступною.

- **Фото (1, 6):** повне зображення → підпис → дія, якщо потрібна. Портрети не обрізаються.
- **Анімація (3, 4):** текст → сцена спільної висоти → запуск. Після завершення текст змінюється на результат, запуск — на контурну кнопку Nochmal. Другого видимого підпису немає.
- **Гра (2, 5, 7, 8):** завдання → інструкція → прогрес → поле та керування → результат і нагорода → підказка або повтор. День 7 використовує наявну інструкцію без додаткового заголовка.

Спільні класи: `gift-card-header`, `gift-panel`, `gift-task`, `gift-instructions`, `gift-progress`, `gift-feedback`, `gift-reward`, `gift-actions`. Функція `arrangeGift` переміщує єдиний текстовий вузол `ch` у потрібне місце, без дублювання ID. Нові дні слід підключати до відповідного шаблону.

Правила дат, ключі сховища, ілюстрації та механіки подарунків залишаються незалежними від цих стилів.
