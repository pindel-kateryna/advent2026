## Перегляд і зміни

- Маленька ⚙ під календарем відкриває поле коду. Код `6652` вмикає перегляд усіх днів; «Vorschau beenden» повертає звичайний календар. Після перезавантаження доступ знову закритий. Пробний прогрес окремий від справжнього. Параметр `?vorschau` не розблоковує календар. Це зручний прихований режим, а не серверний захист.
- Звичайне відкриття налаштоване на 1–24 грудня **2026**, часовий пояс Europe/Berlin.
- Тексти подарунків редагуються в `site/js/content.js`: `D`, константи окремих ігор і `COPY`.
- Підказка схованки для дня 5 — `LOTUS_CONFIG.giftHint`. Поки значення порожнє, блок прихований.
- Картинки завантажуються при відкритті відповідного подарунка. На старті календар не завантажує приховані ілюстрації.
- Для шрифтів Google Fonts потрібен інтернет; без нього працюють системні шрифти.

## Публікація

Публікуй **лише вміст `site/`**. У налаштуваннях хостингу ця папка має бути коренем сайту. Сайт статичний: встановлення залежностей і збирання не потрібні.

`references/` містить особисті оригінали й архів, тому її немає в `site/` і вона виключена через `.gitignore`. У Vercel використовуй Root Directory `site`.

## Зображення

Усі вебкопії — WebP зі збереженням прозорості, пропорцій та повного полотна. Персонажі зазвичай до 960 px, маленькі предмети — 192–320 px. Два фони дня 8 зберігають повні 1086 × 1448 для точного суміщення масок. Оригінали збережені окремо без змін. Загальна вага картинок зменшена з 21,8 до 2,5 MiB; деталі — [docs/performance.md](docs/performance.md).

Повторна підготовка вебкопій (Pillow потрібен лише для цього скрипта, не для хостингу):

```sh
python3 -m venv /tmp/advent-assets-venv
/tmp/advent-assets-venv/bin/python -m pip install -r scripts/requirements-assets.txt
/tmp/advent-assets-venv/bin/python scripts/prepare_assets.py
```

Список відповідностей оригіналів і вебкопій — `scripts/assets.json`. Для роботи опублікованого сайту ні оригінали, ні цей скрипт не потрібні.

## Перевірки

Потрібен Node.js, зовнішні пакети встановлювати не потрібно:

```sh
node --test tests/*.test.cjs
```

Перевірки охоплюють шляхи до файлів, відкладене завантаження картинок, правила дат, логіку ігор, повтори й відновлення прогресу. DOM у цих тестах спрощений: вони не замінюють перевірку вигляду та реальних жестів у браузері. Спільні шаблони перевірено через локальний HTTP-сервер на телефонному й настільному розмірах. Правила компонування: [docs/gift-layouts.md](docs/gift-layouts.md).

Для браузерного перегляду з кореня проєкту:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory site
```

Відкрий http://127.0.0.1:8765/. Перегляд усіх днів вмикається через ⚙ і код, описаний вище.

## Прогрес

Ключі попереднього прогресу залишилися тими самими: `adv26` та `adv26-day7`; день 8 додатково зберігає набір знайдених зірочок у `adv26-day8`. Збережений прогрес на тому самому вебдомені сумісний із новою структурою. Він прив'язаний до браузера й адреси сайту: перенесення з локального файлу на вебдомен не переносить його автоматично; для `file://` браузер також може розділяти сховище між шляхами файлів.
